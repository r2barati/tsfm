# TSFM state of the art as of 27 September 2026

## Read this before comparing rankings

There is no defensible single SOTA model. A result is meaningful only with its task protocol, checkpoint, metric, benchmark version, covariates, horizon, training-data overlap status, and date. The table below identifies candidate leaders by capability and evidence status. A model-team claim is reported as a claim, not as independently established fact.

## Key release facts to pin in any rerun

- **TimesFM 2.5:** 200M backbone, 16,384 context, optional 30M quantile head up to 1,000 horizon, XReg covariate pathway, LoRA examples; released code is open but exact checkpoint terms should be checked. [Repo](https://github.com/google-research/timesfm)
- **TimesFM 3:** 330M, >1T real/synthetic points, native multivariate claim, non-commercial checkpoint terms; announcement only at cutoff. [Model card](https://huggingface.co/google/timesfm-3.0-pytorch)
- **Chronos-2:** 120M base and 28M small, encoder-style, group attention, synthetic multivariate construction, direct quantile forecasts; source code and weights released under Apache-2.0 per model card. [Paper](https://arxiv.org/abs/2510.15821), [card](https://huggingface.co/amazon/chronos-2)
- **Moirai 2.0:** ~11M released small model in model card; decoder-only, quantile loss and multi-token prediction; paper reports scaling plateau/longer-horizon degradation. [Paper](https://arxiv.org/abs/2511.11698)
- **Toto 2.0:** 4M–2.5B family, Apache-2.0 open weights, trained on telemetry plus synthetic data; model-family pretraining data differs from earlier public-data foundations. [Paper/repo](https://github.com/DataDog/toto)
- **TiRex-2:** July 2026 preprint; recurrent multivariate/covariate and streaming claims. Confirm checkpoint, commercial license, and model version before deployment. [Paper/project](https://arxiv.org/abs/2607.01204)
- **TabPFN-TS:** current integration is versioned software; 15 Sep 2026 defaults changed to TabPFN-3.5. Historical “TabPFN-TS ranks first on GIFT” refers an older date and should not be repeated as current SOTA. [Repo](https://github.com/PriorLabs/tabpfn-time-series)

## Benchmark-specific status

- **GIFT-Eval:** mixed point/probabilistic and multivariate benchmark. Original Moirai overlap study shows data leakage can shift results. Do not use leaderboard ranks without release and leak flag. [Paper](https://arxiv.org/abs/2410.10393)
- **fev-bench:** best standardized covariate-aware task interface among listed benchmarks; bootstrap CIs and skill/win metrics. [Paper](https://arxiv.org/abs/2509.26468)
- **TIME:** newest broad fresh-data static benchmark at cutoff, with 50 datasets and 98 tasks. [Paper](https://arxiv.org/abs/2602.12147)
- **BOOM:** useful telemetry benchmark with known Toto domain overlap. [Paper](https://arxiv.org/abs/2505.14766)
- **Chronos Benchmark II:** reference historical Chronos OOD benchmark; later public models may have seen the data. [Paper](https://arxiv.org/abs/2403.07815)
- **LTSF/Monash:** valuable old baselines and task diversity, but public and likely contaminated for modern large-corpus pretraining.
- **TS-Arena/Impermanent:** better prospective temporal protection; compare energy/GitHub tasks separately from cross-domain static suites. [TS-Arena](https://ts-arena.live/about), [Impermanent](https://arxiv.org/abs/2603.08707)

## SOTA wording recommendation

Use “best reported by model authors on benchmark X/version Y, metric Z, zero-shot protocol, cutoff date D.” For unverified current leaderboards use “candidate frontier release” or “announcement claim.” Avoid unqualified “state of the art.”
